# Security policy

## Report a vulnerability privately

Please email `support@hiredata.com` with the subject `Security: HireData skills`.

Include the affected skill or file, the impact, reproduction steps, and any suggested mitigation. Do not open a public issue for vulnerabilities, credentials, customer data, OAuth details, or other sensitive information.

This repository contains instructions and plugin configuration; the HireData MCP service is operated separately. For an MCP or HireData product vulnerability, use the same private reporting route and identify the affected service.

We will acknowledge a report, investigate it, and coordinate disclosure and remediation as appropriate. Please avoid accessing or modifying data that is not yours while researching a report.
